## Acceptance criteria

| ID | Acceptance criterion |
| --- | --- |
| AC1 | Select one specific pending task across all pets. Distinguish separate objects even when pet names or task details match. Completed tasks are not editable. |
| AC2 | Prepopulate title, duration, priority, recurrence, scheduled time, and due date from the selected task. Switching tasks must not carry another task's values into the editor. |
| AC3 | Support editing all seven fields. Title maps to `Task.name`; recurrence supports `once`, `daily`, and `weekly`. Blank scheduled time or due date clears that optional value. |
| AC4 | Change task data only when **Save changes** is submitted. Opening the editor, typing, switching selection, and ordinary reruns must not modify tasks. |
| AC5 | Save through `Task.update_details()`. Invalid input must show a readable error and leave every task field unchanged, including otherwise valid proposed edits. |
| AC6 | Preserve the selected Task object, its owning Pet, completion state, and position in the pet's task collection. Do not replace, append, remove, or complete tasks during editing. |
| AC7 | Clear the cached plan only after a successful save that changes task data. Invalid submissions, navigation, and unchanged submissions retain the existing plan. Existing invalidation for other app actions remains intact. |
| AC8 | After saving, the displayed chronological order and same-start-time warnings reflect the updated data without another user action. Untimed tasks remain last. |
| AC9 | Changing recurrence does not create another task. Later completion still creates exactly one next occurrence using the existing backend behavior. |
| AC10 | Repeated saves and reruns do not create duplicates. If the selected task becomes completed before submission, reject the stale edit safely. |
| AC11 | No-pet, no-task, and all-completed states display helpful guidance without exceptions. |
| AC12 | Preserve existing creation, completion, filtering, priority scheduling, time budgets, exact-time conflict semantics, and all 97 baseline tests. |

The earlier wording "all seven fields" is retained. It means title, duration,
priority, recurrence, scheduled time, and due date: six editable task attributes.
Selection is the seventh editor control, not a new task attribute. Both
candidates receive this explicit clarification; do not invent another field.

## Shared behavior details

- The editor lists all pending tasks independently of browse filters.
- Selecting another task discards unsaved edits and loads that task's values.
- Normalize title and time whitespace as in the existing UI/backend. A blank
  scheduled time becomes `None`. A cleared single-date input becomes `None`.
- Compare normalized saved values when deciding whether anything changed.
  An unchanged submission preserves the current plan.
- Preserve current session objects. Do not move a task between pets, change its
  completion date, or alter any nonselected task.
- Completion after an edit remains the existing `Pet.complete_task()` workflow.
- On stale submission, do not redirect the submitted values to a different task.
  Leave the completed task and all other tasks unchanged, and show guidance.
- A successful change shows `st.success`; rejected values show `st.error`.
  Existing conflict warnings continue to use `st.warning`.
- No persistence, deletion, interval-overlap detection, or unrelated UI redesign.

These controls make the exact same AppTest file usable against both candidates.

| Streamlit control | Fixed key | Values / behavior |
| --- | --- | --- |
| `st.selectbox` | `edit_task` | Unique string options in pending `Owner.get_all_tasks()` order. Each displayed string includes pet and task names and a distinguishing number/token. Use strings as the actual selectbox options so AppTest can select by the displayed string. |
| `st.text_input` | `edit_title` | Selected task name |
| `st.number_input` | `edit_duration` | Positive whole minutes; prevent invalid numeric values at the widget or reject them atomically |

| `st.text_input` | `edit_scheduled_time` | HH:MM or blank |
| `st.date_input` | `edit_due_date` | Single date or `None`, clearable |
| Button or form submit button | `edit_save` | Label `Save changes` |

When pending tasks exist, expose one editor with these keys. Default selection
may be the first pending task. With none, hide/disable the editor and show useful
`st.info` guidance. Keep existing widget keys and state entries (`owner`,
`scheduler`, and cached `plan`) working. Keep browse-table column names `Task`,
`Pet`, `Time`, and `Status`; either a table or dataframe is accepted.

The tests inspect visible controls, displayed rows/warnings, public backend
objects, and the existing cached plan. They do not call candidate helper
functions. One test wraps and delegates to the real `Task.update_details()` to
verify required API use; it does not mock its behavior.

```python
"""Frozen UI acceptance tests shared by both prompt-comparison candidates.

Run from a candidate root. These tests drive the public widget interface and
real backend objects; they do not depend on candidate helper functions.
"""

from datetime import date, timedelta
from pathlib import Path

import pytest
from streamlit.testing.v1 import AppTest

import pawpal_system
from pawpal_system import Owner, Pet, Scheduler, Task


APP_ROOT = Path(__file__).resolve().parents[1]


def run_app(at):
    """Run one UI event and fail clearly on an unhandled app exception."""
    at.run(timeout=15)
    assert not at.exception, [str(error.value) for error in at.exception]
    return at


def widget(at, kind, key):
    """Find a control by the agreed public key, independently of layout."""
    matches = [element for element in getattr(at, kind) if element.key == key]
    assert len(matches) == 1, f"Expected one {kind} with key {key!r}"
    return matches[0]


def start_app(owner):
    """Seed real session objects and a real cached plan before UI startup."""
    assert Path(pawpal_system.__file__).resolve() == APP_ROOT / "pawpal_system.py"
    at = AppTest.from_file(str(APP_ROOT / "app.py"), default_timeout=15)
    scheduler = Scheduler()
    plan = scheduler.generate_plan(owner, on_date=date.today())
    at.session_state["owner"] = owner
    at.session_state["scheduler"] = scheduler
    at.session_state["plan"] = plan
    run_app(at)
    assert at.session_state["owner"] is owner
    assert at.session_state["plan"] is plan
    return at, plan


def select_pending(at, index):
    """Select by the agreed pending collection order, not private IDs."""
    selector = widget(at, "selectbox", "edit_task")
    selector.select(selector.options[index])
    return run_app(at)


def save(at):
    """Submit the editor and inspect the immediately resulting UI."""
    widget(at, "button", "edit_save").click()
    return run_app(at)


def collection_ids(owner):
    """Capture collection order and object identities without equality lookup."""
    return [(id(pet), [id(task) for task in pet.tasks]) for pet in owner.pets]


def task_details(owner):
    """Take copies so later mutation cannot alter the expected values."""
    return [vars(task).copy() for _, task in owner.get_all_tasks()]


def assert_editor_values(at, task):
    """Check all six editable attributes against the selected real task."""
    assert widget(at, "text_input", "edit_title").value == task.name
    assert widget(at, "number_input", "edit_duration").value == task.duration_minutes
    assert widget(at, "selectbox", "edit_priority").value == task.priority
    assert widget(at, "selectbox", "edit_recurrence").value == task.recurrence
    assert widget(at, "text_input", "edit_scheduled_time").value == (task.scheduled_time or "")
    assert widget(at, "date_input", "edit_due_date").value == task.due_date


def browse_names(at):
    """Find the browse view by public columns, allowing table or dataframe."""
    matches = []
    for element in list(at.table) + list(at.dataframe):
        frame = element.value
        if {"Pet", "Task", "Time", "Status"}.issubset(frame.columns):
            matches.append(frame)
    assert len(matches) == 1, "Expected one visible task browse table"
    return matches[0]["Task"].tolist()


def conflicts(at):
    """Read the existing backend conflict warnings from the rendered UI."""
    return [str(item.value) for item in at.warning if str(item.value).startswith("Conflict on ")]


@pytest.fixture
def care():
    """Use today's date with fresh, independent objects for every test."""
    today = date.today()
    first = Task("Walk", 10, "high", "once", scheduled_time="09:45", due_date=today)
    second = Task("Feeding", 5, "medium", "daily", scheduled_time="09:05", due_date=today)
    untimed = Task("Grooming", 15, "low", "weekly")
    dog = Pet("Biscuit", "dog", tasks=[first, untimed])
    cat = Pet("Mochi", "cat", tasks=[second])
    owner = Owner("Jordan", 40, True, [dog, cat])
    yield owner, dog, cat, first, second, untimed, today
    assert date.today() == today, "Local date changed: rerun both candidates' verification"


def test_pending_selector_disambiguates_equal_objects_and_ignores_browse_filters():
    """AC1/AC6: identical details do not make distinct objects interchangeable."""
    first, second, third = [Task("Care", 5) for _ in range(3)]
    done = Task("Finished", 5)
    done.mark_complete()
    pets = [Pet("Mochi", "cat", tasks=[first, second, done]), Pet("Mochi", "cat", tasks=[third])]
    owner = Owner("Jordan", 30, pets=pets)
    at, plan = start_app(owner)
    original_ids = collection_ids(owner)
    options = widget(at, "selectbox", "edit_task").options
    assert len(options) == 3
    assert len(set(options)) == 3
    assert all("Mochi" in option and "Care" in option for option in options)
    assert all("Finished" not in option for option in options)

    widget(at, "text_input", "pet_filter").set_value("Unknown")
    widget(at, "selectbox", "status_filter").select("Completed")
    run_app(at)
    assert widget(at, "selectbox", "edit_task").options == options
    assert at.session_state["plan"] is plan

    select_pending(at, 1)
    widget(at, "text_input", "edit_title").set_value("Edited second")
    save(at)
    assert first.name == "Care"
    assert second.name == "Edited second"
    assert third.name == "Care"
    assert done.name == "Finished" and done.completed
    assert collection_ids(owner) == original_ids

    select_pending(at, 2)
    widget(at, "text_input", "edit_title").set_value("Edited other pet")
    save(at)
    assert third.name == "Edited other pet"
    assert first.name == "Care" and second.name == "Edited second"
    assert collection_ids(owner) == original_ids


def test_switching_tasks_discards_drafts_and_preserves_tasks_and_plan(care):
    """AC2/AC4/AC7: widget reruns never commit an unsaved draft."""
    owner, _, _, first, second, untimed, _ = care
    at, plan = start_app(owner)
    before = task_details(owner)
    assert_editor_values(at, first)
    widget(at, "text_input", "edit_title").set_value("Unsaved draft")
    widget(at, "number_input", "edit_duration").set_value(21)
    run_app(at)
    assert task_details(owner) == before
    assert at.session_state["plan"] is plan

    select_pending(at, 2)
    assert_editor_values(at, second)
    select_pending(at, 1)
    assert_editor_values(at, untimed)
    select_pending(at, 0)
    assert_editor_values(at, first)
    assert task_details(owner) == before
    assert at.session_state["plan"] is plan


def test_save_all_fields_uses_real_update_and_preserves_identity(care, monkeypatch):
    """AC3/AC5/AC6/AC7: edit in place through the existing atomic API."""
    owner, dog, _, first, _, _, today = care
    at, _ = start_app(owner)
    original_ids = collection_ids(owner)
    other_details = [vars(task).copy() for _, task in owner.get_all_tasks() if task is not first]
    real_update = Task.update_details
    updated_objects = []

    def record_real_update(self, **changes):
        updated_objects.append(self)
        return real_update(self, **changes)

    monkeypatch.setattr(Task, "update_details", record_real_update)
    widget(at, "text_input", "edit_title").set_value("  Revised walk  ")
    widget(at, "number_input", "edit_duration").set_value(17)
    widget(at, "selectbox", "edit_priority").select("low")
    widget(at, "selectbox", "edit_recurrence").select("weekly")
    widget(at, "text_input", "edit_scheduled_time").set_value(" 07:15 ")
    widget(at, "date_input", "edit_due_date").set_value(today + timedelta(days=3))
    save(at)

    assert any(task is first for task in updated_objects)
    assert vars(first) == {
        "name": "Revised walk", "duration_minutes": 17, "priority": "low",
        "recurrence": "weekly", "last_completed_date": None,
        "scheduled_time": "07:15", "due_date": today + timedelta(days=3),
    }
    assert dog.tasks[0] is first
    assert collection_ids(owner) == original_ids
    assert [vars(task) for _, task in owner.get_all_tasks() if task is not first] == other_details
    assert "plan" not in at.session_state
    assert at.success, "A successful change should show a confirmation"
```
